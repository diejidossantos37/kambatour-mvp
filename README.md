# 🌍 KambaTour — O Seu Guia Amigo em Angola
> **Ecossistema Inteligente e Plural de Turismo Nacional**

O **KambaTour** é uma plataforma inovadora projetada para revolucionar o turismo em Angola. Unindo o conceito cultural de hospitalidade (*Kamba* - Amigo) a uma arquitetura de software modular de alta integridade, o sistema oferece recomendação algorítmica de roteiros, mapeamento GIS e reservas rastreáveis.

---

## 🏛️ Arquitetura de Software (10 Módulos de Domínio)

O ecossistema foi projetado sob os princípios de **Domain-Driven Design (DDD)** e **Programação Orientada a Objetos (POO)** com tolerância zero a erros de estado:

1. **M1 — UI/UX Presentation Layer:** Interface Single Page Application (SPA) responsiva.
2. **M2 — IAM (Identity & Access Management):** Controle de privilégios via RBAC e dados encapsulados.
3. **M3 — Catalog & Inventory:** Gestão de recursos turísticos e filtros provínciais em tempo real.
4. **M4 — Booking Engine:** Validação estrita de datas, limites de lotação e transições de estado.
5. **M5 — Recommendation Engine:** Algoritmo de inferência de perfil para itinerários personalizados.
6. **M6 — Payment Gateway Simulator:** Emissão de vouchers e conciliação simulada (MCX Express / Visa).
7. **M7 — Trust & Review System:** Estrutura para reputação e avaliações.
8. **M8 — Messaging & Notifications:** Alertas em tempo real.
9. **M9 — GIS & Telemetry:** Mapeamento geoespacial vetorial via Leaflet / OpenStreetMap.
10. **M10 — Audit & Security Logs:** Console imutável de logs para investidores.

---

## 🛠️ Stack Tecnológica (MVP Client-Side)
- **Frontend:** HTML5, CSS3 Customizado, JavaScript (ES6+ POO)
- **UI Framework:** Bootstrap 5.3
- **Geoespacial:** Leaflet.js (OpenStreetMap)
- **Design System:** Paleta Corporativa (Amber / Emerald Green / Obsidian Dark)
